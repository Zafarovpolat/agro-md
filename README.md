# TractorMD — новый сайт (Молдова). Фронт по пожеланиям клиента

Статическая витрина импорта японской техники: **статусы товара, счётчик поставки, бронирование до прибытия**.
Сделана как чистый HTML/CSS/JS — дальше натягивается на WordPress (план в конце).

**Название, телефоны, адрес, e-mail — заглушки**, меняются в одном файле `js/data.js` (и позже в настройках WP).

---

## Запуск

```bash
cd agro-md
python3 -m http.server 8090        # → http://localhost:8090
```

Или просто открыть `index.html` в браузере — сборка не нужна, зависимостей нет (никаких CDN и внешних шрифтов).

## Файлы

```
index.html      витрина: hero, «как купить», контейнеры, каталог с фильтрами, контакты, бронь
product.html    карточка техники: галерея, характеристики, счётчик, бронь, похожие позиции
admin.html      ДЕМО-админка: показывает клиенту, как менеджер будет управлять сайтом
css/style.css   дизайн-система (статусы, счётчики, карточки, адаптив)
js/data.js      данные: товары, контейнеры, словарь RU/RO, контакты
js/main.js      логика: рендер, фильтры, счётчики, бронь, i18n, демо-правки «из админки»
img/            фото (WebP)
public/         favicon
```

## Как реализованы пожелания клиента

| Пожелание | Реализация |
|---|---|
| Статус «в дороге» + фото | 4 статуса: `stock` / `transit` / `reserved` / `sold`. Позиции «в дороге» показываются с фото, ценой и датой прибытия, стикер «В дороге» |
| Стикер в карточке | Цветной бейдж на фото: зелёный «В наличии», оранжевый пульсирующий «В дороге», янтарный «Забронировано», серый «Продан» |
| «Осталось N дней» | Блок счётчика: `До прибытия 55 дн.` + прогресс-бар пути контейнера |
| Кнопка «Забронировать» | На позициях «в дороге» — «Забронировать» вместо «Купить»; у наличия — «Оставить заявку» |
| Форма брони | Имя, Фамилия, Телефон, комментарий, галочка согласия. Заявка уходит менеджеру, товар блокируется после подтверждения |
| Стикер «Забронировано» | Появляется после «Подтвердить бронь» в админке, кнопка становится неактивной |
| Ручное управление | Никакой автоматики: менеджер сам ставит статус и дату. Демо-админка показывает этот процесс |
| Идеи с образца | Фильтр «только не забронированные», сортировка «по дате прибытия», поиск по серийному номеру, блок «Контейнеры в пути», условия скидок, «каталог обновлён ДД.ММ ЧЧ:ММ», WhatsApp с текстом о конкретном экземпляре |

### Логика счётчика поставки (как договорились — «логичная»)

Считается в браузере посетителя от **даты прибытия** и сегодняшнего дня — закешированные числа невозможны.

| Ситуация | Что видит клиент |
|---|---|
| В пути, срок не близко | 🚚 **До прибытия 55 дн.** · поставка ожидается 26.11.2026 · Контейнер WML38-894 + прогресс-бар |
| В пути, осталось ≤ 7 дней | 📦 **Ожидается со дня на день** (3 дня) — зелёный блок |
| Срок истёк | ⚠ **Рейс задерживается** · точную дату подтверждает менеджер — без отрицательных чисел |
| Уже в стране | ✅ **В Молдове с 20.09.2026** — счётчик заменяется фактом, товар можно смотреть на складе |
| Продан | Счётчика нет, кнопка «Смотреть похожие» |

Прогресс-бар считается от даты постановки в поставку до даты прибытия: видно, что «5 из 60 дней прошло».

## Что в демо — не финальное

- Заявки **не отправляются на e-mail** (в демо сохраняются в браузере, чтобы их было видно в демо-админке). В WordPress — отправка письма менеджеру.
- Правки статусов в `admin.html` работают в браузере (localStorage) — это макет для показа логики, не настоящая админка.
- Товары и контейнеры — демонстрационные. Фото — сгенерированные плейсхолдеры вместо реальных съёмок.
- Бренд «TractorMD», телефоны, адрес, e-mail — заглушки.

## Проверено

Автотесты на jsdom (18 проверок): фильтры и поиск по серии, все 4 состояния счётчика, отсутствие отрицательных чисел, переключение RU/RO, полный флоу «бронь → заявка → подтверждение менеджером → стикер на витрине», отказ от брони, пересчёт даты при смене срока поставки, отражение правок админки на витрине.

## План переноса на WordPress (следующий этап)

**Структура (ACF-поля карточки техники):**

| Поле | Тип | Назначение |
|---|---|---|
| Название | text | «Yanmar FF205» |
| Марка, Модель | taxonomy / text | фильтр по марке |
| Серия, Код позиции | text | поиск по серийному номеру |
| Контейнер | relation → CPT «Контейнеры» | группировка и блок «Контейнеры в пути» |
| Цена | number | пусто = «По запросу» |
| **Статус** | select: в наличии / в дороге / забронировано / продан | стикер и логика кнопки |
| Срок поставки, дней | number | ввод менеджера |
| Дата прибытия | date | счётчик (можно сдвинуть вручную) |
| Мощность, Наработка, Привод, Кабина | text | характеристики |
| Описание RU / RO | wysiwyg / textarea | двуязычность |
| Фото | gallery (до 15, перетаскивание) | галерея, первое — главное |
| Видео | url | опция |

**CPT:** `tractor` (техника) + `container` (номер, дата прибытия, примечание) + `booking` (заявки: ФИО, телефон, товар, статус обработки).
**Заявки:** письмо на e-mail менеджера + копия клиенту, антиспам, лог.
**Плагины:** ACF Pro, WPML или Polylang (RU/RO), SMTP-плагин. Тема — своя, вёрстка переносится 1:1.
**Роли:** администратор и менеджер (менеджер видит только технику и заявки).
